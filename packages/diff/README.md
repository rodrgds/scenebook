# `@scenebook/diff`

Functional, visual, semantic, geometry, narrative, and privacy change classification for Scenebook evidence.

## Install

```sh
npm install @scenebook/diff
```

The package is ESM-only and requires Node.js 22 or newer. Compiled JavaScript, declarations, and the corresponding TypeScript source are included.
