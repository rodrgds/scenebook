# `@scenebook/policy`

Explainable Channel policy evaluation and atomic Release readiness decisions for Scenebook.

## Install

```sh
npm install @scenebook/policy
```

The package is ESM-only and requires Node.js 22 or newer. Compiled JavaScript, declarations, and the corresponding TypeScript source are included.
