# `@scenebook/core`

Deterministic identifiers, canonical serialization, safe paths, Scene graph utilities, and release rules for Scenebook.

## Install

```sh
npm install @scenebook/core
```

The package is ESM-only and requires Node.js 22 or newer. Compiled JavaScript, declarations, and the corresponding TypeScript source are included.
